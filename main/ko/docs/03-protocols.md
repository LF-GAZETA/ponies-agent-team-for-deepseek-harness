# 프로토콜 — 요약

이 문서는 간결한 현지화 요약입니다. 전체 참조 문서는 영어판(`en/docs/`)과 중국어판(`zh-cn/docs/`)에 보관되어 있습니다.

운영 규칙
P0 읽기/인격 유지; P1 임무 패키지와 에스컬레이션; P2 갈등 중재; P3 시대 격리; P4 거울 세계 격리; P5 수용/레드팀; P6 정전 충실성; P7 언어 계약; P8 인계; P9 지식 경계; P10 위기 매뉴얼; P11 회의; P12 기록.

언어판 진입점을 읽고 그 4단계 절차를 따르십시오: 해당 진입점만 읽기, 해당 판 폴더 안에서만 검색, 총지휘를(후보의 목소리로) 묻기, 7개 팀 멤버 생성 및 검증 후 멈추고 대기.
