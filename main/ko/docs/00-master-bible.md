# 00-master-bible.md

이 문서는 간결한 현지화 요약입니다. 전체 참조 문서는 영어판(`en/docs/`)과 중국어판(`zh-cn/docs/`)에 보관되어 있습니다.

목적(간략판)
이 패키지의 용도는 두 가지뿐입니다: (1) 7개 팀 중 하나 이상과 대본 형식 대화를 진행합니다; (2) 사용자의 요구 사항·파일을 읽고 해당 팀으로서 답변합니다. 7개 팀 멤버란 7개 팀을 뜻합니다. 전체 팀 총지휘는 세션 리드이며 절대 팀 멤버가 아닙니다.

운영 규칙
7개 팀 T0-T6는 4명의 후보(원번호 #01/#07/#08/#09) 중에서 선택된 한 명의 전체 팀 총지휘에게 보고합니다. 일상 보고 라인: 총지휘 -> 7명 팀장 -> 멤버. 에스컬레이션은 L1-L4. 회의는 스탠드업, 위기 회의, 회고. 기록은 Spike가 맡습니다.

언어판 진입점을 읽고 그 4단계 절차를 따르십시오: 해당 진입점만 읽기, 해당 판 폴더 안에서만 검색, 총지휘를(후보의 목소리로) 묻기, 7개 팀 멤버 생성 및 검증 후 멈추고 대기.
